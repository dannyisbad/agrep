# Semantic performance evidence

See [the investigation report](../../docs/SEMANTIC-PERFORMANCE.md) for results,
limits and the source changes. This directory contains synthetic inputs/results;
it contains no private conversation history or model weight files.

- `early/` and `runners/`: original exploratory logs and the orchestration/microbenchmark sources, preserved before scratch cleanup.
- `machine.json`: host, toolchain, source revisions and executable hashes.
- `final-plan.json`: sampling order and preconditions, including the host restart.
- `matched-{reference,before,after}.jsonl`: final matched bulk samples. Each fresh
  process embeds eight identical batches. Each engine/fixture/device has three
  samples; all batch times and adjacent load averages are retained.
- `query-{reference,before,after}.jsonl`: fresh-process query samples, with full
  output/exit status and adjacent load averages. The summaries derive p50/p95
  from every sample. The after-binary also records the actual keyword stage. The final reference
  query run is explicitly contended and is not a matched-host speedup comparison.
- `summary.json`: derived comparison, generated by `scripts/semantic_report.py`.
- `*.waits.jsonl`: every load check while waiting to start a sample.
- `pre-restart-*`: complete earlier CPU, Metal and query measurements, retained
  separately because the host was externally restarted before the final epoch.
- `loaded-*`, `pilot-*`, `*-sweep*`, `metal-fine*`, `before-bulk*`,
  `reference-bulk*`, `projection-pilot*`: exploratory/contended measurements.
  Their actual settings remain recorded; they are not silently pooled into the
  final protocol. Cancellation/restart records explain interrupted campaigns.
- `profile-*`, `query-profile-*`: synchronized diagnostics. Device completion
  waits include driver/queue delay; instrumented wall times are not throughput.
- `quality-*`: actual-model parity, ordered neighbors and labeled recall gates.
  `reference-q8-quality.json` is a separate diagnostic of the old q8 profile.
- `fmt-*`, `clippy-*`, `tests-*`, `build-*`, `finish-exits.jsonl`: validation and
  build evidence. Earlier checks are preserved beside the final checks.

Every throughput/latency measurement uses explicit scratch roots and nice 10.
The reference is the read-only 0.4.9 checkout with its Python environment, not the
installed CLI. The scripts do not rely on the scratch data surviving cleanup.
