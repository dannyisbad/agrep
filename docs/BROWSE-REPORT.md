# Browse and diagnostics

Chats and summary resolve caller identity through the same implementation as search.
History and handles share indexed session reference resolution. Summary reads tool
event time, input and output through the canonical evidence reader; control-event
timestamps still require the engine integration.

Status and doctor read typed enrollment, check each block/file/hook by kind, and use
the semantic module for model presence and coverage. Doctor refresh is incremental;
corruption prompts retain the database and WAL and copy harness rules into repair.
Run/resume preserve child arguments and status without an additional run-record store.

The independent synthetic browse benchmark was removed. Performance acceptance uses
the common CI harness and its documented corpus-derived budgets. No measurements in
this document claim acceptance for the merged tree.
